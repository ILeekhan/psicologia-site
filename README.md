## 📌 Sobre o Projeto

O **Psicologia Site** utiliza uma estrutura simples, com separação dos arquivos de marcação, estilização, scripts e imagens — facilitando a organização, manutenção e evolução do código.

---

## 🎯 Objetivos

- ✅ Praticar desenvolvimento front-end
- ✅ Aplicar conceitos de **HTML semântico**
- ✅ Desenvolver interfaces utilizando **CSS**
- ✅ Utilizar **JavaScript** para funcionalidades e interações
- ✅ Organizar arquivos de um projeto web
- ✅ Aprimorar conhecimentos de **Git e GitHub**

## 🚀 Como Executar

> 💡 O projeto utiliza apenas tecnologias front-end — **não requer instalação de dependências**.

```bash
# 1. Clonar o repositório
git clone https://github.com/ILeekhan/psicologia-site.git

# 2. Acessar a pasta
cd psicologia-site

# 3. Abrir no VS Code
code .
```

### 4. Executar a página
- Abra o arquivo `html/index.html` diretamente no navegador, **ou**
- Utilize a extensão **Live Server** do VS Code para visualização durante o desenvolvimento.
